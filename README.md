## Data
The raw data (23 CSV tables, 2.9M rows, Oct 2018 – Oct 2026) is **not** in this repo: it is company data and one file is larger than GitHub's 100 MB limit.
To run the notebook, put the data in `Cottonil_project/COTTONIL/COTTONIL_Data/02_TABLES/` next to this file.
