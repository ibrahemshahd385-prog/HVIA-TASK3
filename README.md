## Data
The raw data (24 CSV files: 23 tables + a data dictionary, 2.9M rows, Oct 2018 – Oct 2026, plus a public product catalog) is **not** in this repo:
it is company data and one file is larger than GitHub's 100 MB limit.
To run the notebook, put the data in `Cottonil_project/COTTONIL/COTTONIL_Data/` (folders `01_CATALOG` and `02_TABLES`) next to this file.
